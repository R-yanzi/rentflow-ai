# RentFlow AI 分阶段开发路线

## 1. 执行原则

1. 一次只推进一个里程碑；
2. 每个里程碑必须形成可演示闭环；
3. 先完成确定性业务能力，再交给 Agent 编排；
4. 测试、文档和错误处理属于功能的一部分；
5. 未完成当前验收，不提前引入下一阶段框架。

## 2. 总体路线

| 阶段 | 目标 | 后端 | 前端 | 状态 |
|---|---|---|---|---|
| M0/F0 | 工程基础 | 配置、数据库、迁移、健康检查 | Vue 工程基础 | 已完成 |
| M1/F2 | 确定性搜索 | CRUD、筛选、PostGIS、种子数据 | 列表、地图、详情 | 后端完成，前端 F2 开发中 |
| M2/F1 | 自然语言闭环 | DeepSeek、条件映射、异常 | 智能找房、条件预览 | 已完成 |
| M3/F3 | 决策检索 | 地点、通勤、向量、排序、松弛 | 对比、评分、What-if | 未开始 |
| M4/F4 | RAG | 文档、Chunk、引用、评测 | 知识助手、引用面板 | 未开始 |
| M5/F4 | Agent | LangGraph、状态、SSE、恢复 | Agent Timeline | 未开始 |
| M6/F5 | 企业业务 | 认证、RBAC、预约、审批 | 账户、预约、管理端 | 未开始 |
| M7/F6 | 工程交付 | 监控、CI、部署、性能、安全 | 看板、评测管理 | 未开始 |

## 3. M0 工程基础

### 功能

- FastAPI 应用工厂；
- Pydantic Settings；
- PostgreSQL/PostGIS/pgvector Docker；
- SQLAlchemy Async；
- Alembic；
- 健康与就绪检查；
- Ruff、Pyright、pytest。

### 验收

- API、数据库和扩展可启动；
- 迁移达到 head；
- 测试和静态检查通过。

状态：已完成。

## 4. M1 确定性房源搜索

### 功能

- Listing 模型；
- 创建、详情和列表；
- 预算、区域、户型、宠物、日期筛选；
- PostGIS 半径与距离排序；
- 300 条可复现上海合成数据；
- 参数和数据规则测试。

### 验收

- 硬条件无违规；
- 空间查询返回米制距离；
- 分页稳定；
- 重复种子执行不重复插入。

状态：已完成。

## 5. M2 自然语言搜索闭环

### M2.1 结构化提取

- `RentalRequirements`；
- LLM Provider 协议；
- DeepSeek JSON Output；
- Pydantic 二次校验；
- Stub 测试。

状态：已完成。

### M2.2 条件映射

- 将硬条件映射为 `ListingSearchParams`；
- 显式返回未处理条件；
- 复用 Listing Service；
- 添加映射单元测试。

状态：已完成。

### M2.3 统一异常

- LLM 未配置；
- 超时；
- 上游状态错误；
- 空白响应；
- 非法 JSON；
- Schema 不匹配；
- 统一错误码和 request_id。

状态：已完成。

### M2.4 阶段验收

- 一条自然语言请求可返回数据库房源；
- 硬条件实际执行；
- 通勤和偏好未实现时明确提示；
- CI 测试不消耗真实 API；
- 真实 DeepSeek 仅进行受控冒烟测试。

状态：已完成。已通过 Stub 自动测试、真实 DeepSeek 冒烟测试和浏览器端到端验收。

## 6. F0/F1 前端起步

后端 M2 稳定后开始前端，不等待整个后端完成。

### F0

- Vue 3 + TypeScript + Vite；
- Element Plus、Router、Pinia、Axios；
- 环境变量与 API Client；
- 页面级加载与错误提示；
- Tenant Layout 骨架（Admin Layout 随运营功能创建）。

状态：已完成租客端工程基础；管理端 Layout 在进入运营功能时创建，避免空壳页面。

### F1

- 智能找房输入；
- 示例需求；
- 结构化条件预览；
- 自然语言搜索结果；
- 未处理条件提示；
- 加载、错误和空状态。

状态：已完成。当前页面可完成解析、条件确认、确定性搜索和房源卡片展示。

### 验收

- 用户不使用 Swagger 即可完成一次自然语言找房；
- DeepSeek 错误能显示友好提示；
- 结构化条件可见且不会被隐藏。

## 7. M3 GIS、软偏好与决策

### M3.1 上海地点目录

- `locations` 表；
- 地点别名；
- 地点搜索和解析 API；
- 歧义候选与澄清；
- WGS84 坐标统一。

状态：已完成。已实现标准地点与别名表、幂等上海地点目录、搜索/详情/解析 API，以及唯一匹配、歧义和未找到三种稳定结果。

### M3.2 通勤 Provider

- Provider 协议；
- 本地估算实现；
- 外部地图实现预留；
- 缓存、来源和是否估算标记；
- 批量通勤计算。

当前进度：M3.2A 已完成统一 Provider 协议、本地估算实现、步行/骑行/公交/驾车四种模式，以及来源、估算标记和计算时间字段；37 项后端测试通过。下一步实现 M3.2B 通勤结果缓存模型、数据库迁移与 Repository。

### M3.3 Embedding 与 pgvector

- 建立检索评测集；
- 对比候选 Embedding 模型；
- 确定维度后迁移；
- 房源向量生成脚本；
- 模型版本与内容哈希；
- 向量索引。

### M3.4 多目标排序

- 预算、通勤、距离、偏好分项评分；
- 默认权重；
- 稳定排序；
- 得分拆解；
- NDCG 等排序评测。

### M3.5 无结果诊断

- 单约束放宽模拟；
- 新增候选数量；
- 最小放宽成本；
- 用户确认后重搜；
- 不自动修改原条件。

### 验收

- “在张江上班”可解析为地点；
- 通勤结果标明真实/估算来源；
- 软偏好影响排序但不违反硬条件；
- 无结果能给出可执行调整建议。

## 9. M4 租赁知识 RAG

- MinIO 文件存储；
- 版本、哈希和发布状态；
- 上传与列表 API。

### M4.2 摄取管线

- PDF/Markdown/Word 解析；
- 清洗、分块和页码；
- Celery 异步任务；
- Embedding 与写入；
- 幂等和失败重试。

### M4.3 检索与回答

- 元数据过滤；
- 关键词 + 向量混合召回；
- Rerank；
- 带引用回答；
- 无证据拒答；
- Prompt Injection 防护。

### M4.4 评测

- Recall@5；
- MRR；
- 引用准确率；
- 回答忠实度；
- 不可回答识别；
- 跨租户泄漏测试。

### 验收

- 回答可以定位到文档版本、页码和 Chunk；
- 无证据时不生成确定性结论；
- 普通 CI 不调用真实生成模型。

## 10. M5 LangGraph Agent

### 节点

```text
parse_requirements
validate_requirements
request_clarification
resolve_location
search_candidates
calculate_commute
rank_preferences
diagnose_empty_results
generate_explanations
quality_check
```

### 能力

- Typed State；
- Checkpoint；
- 暂停与恢复；
- 节点级重试；
- Tool 超时；
- SSE 公开进度；
- Agent Run 和 Tool Call 记录。

### 验收

- 缺失关键条件时可以暂停并等待用户；
- 失败后可以从合理节点恢复；
- 不展示私有思维链；
- 所有写操作仍通过业务 Service。

## 11. M6 企业业务

### 功能

- 用户、JWT、刷新令牌；
- RBAC；
- 收藏和历史搜索；
- 带看预约；
- 幂等键；
- 时间冲突；
- 人工审批；
- 审计日志；
- 限流与敏感信息脱敏。

### 验收

- 租客不能访问运营接口；
- Agent 不能绕过权限；
- 重复预约请求不产生重复记录；
- 高风险操作未经批准不执行。

## 12. M7 工程交付

### 功能

- OpenTelemetry；
- Langfuse；
- Prometheus/Grafana 或等价指标；
- GitHub Actions；
- Docker Compose 完整部署；
- 性能、故障和安全测试；
- README、架构图、演示视频和评测报告。

### 最终 Demo

1. 正常找房：解析、GIS、排序并解释；
2. 条件冲突：无结果并给出最小放宽建议；
3. RAG：回答租赁问题并展示引用；
4. 高风险操作：预约前暂停等待确认；
5. 运营端：查看 Agent Run、成本和评测失败案例。
